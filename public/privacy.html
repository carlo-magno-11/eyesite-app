EYESITE — Aviso de Privacidad

Última actualización: septiembre de 2026

Responsable

EYESITE es responsable del tratamiento de los datos personales que proporciona el usuario a través de la aplicación y sus servicios inmobiliarios.

Datos tratados

Podemos tratar nombre, correo electrónico, teléfono, ciudad y preferencias inmobiliarias. Al publicar una propiedad podemos tratar la información, fotografías, videos y archivos que el usuario envíe para revisión y publicación.

Ubicación

La ubicación se utiliza cuando el usuario decide emplear funciones del mapa para encontrar propiedades EYESITE cercanas o ubicar una propiedad. Si el usuario no autoriza la ubicación, puede utilizar el mapa sin ella y proporcionar coordenadas manualmente cuando corresponda.

Finalidades

Autenticar cuentas, gestionar favoritos y notificaciones, recibir y moderar solicitudes inmobiliarias, mostrar propiedades publicadas, atender consultas y proteger la plataforma.

Terceros

EYESITE utiliza servicios técnicos necesarios para operar la plataforma, incluyendo Supabase para autenticación, base de datos y almacenamiento, y servicios cartográficos para las funciones de mapa. EYESITE no vende los datos personales de los usuarios.

Conservación y seguridad

Aplicamos controles de acceso y separación entre información pública y privada. Los datos se conservan mientras sean necesarios para las finalidades descritas o cuando exista una obligación legal aplicable.

Eliminación de cuenta

La eliminación de la cuenta puede iniciarse dentro de la aplicación desde la sección “Nosotros”. El proceso elimina la cuenta y los datos asociados que EYESITE controle, salvo información que deba conservarse por obligación legal.

Contacto

Para dudas sobre privacidad o tratamiento de datos: informacion@eyesite.com.
